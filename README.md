# Felkollen

En app för att felanmäla och klaga på vad du vill.

## Kom igång

### Krav

- Node.js installerat

### Installation

1. Klona repot
2. Installera beroenden:

```
npm install
```

### Starta appen

Appen kräver två terminaler som körs samtidigt:

**Terminal 1 — Multer-servern (bilduppladdning):**

```
node server.js
```

**Terminal 2 — React-appen:**

```
npm run dev
```

Öppna sedan [http://localhost:5173](http://localhost:5173) i webbläsaren.

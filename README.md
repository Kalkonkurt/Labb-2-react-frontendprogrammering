Felkollen

En app för att felanmäla och klaga på vad du vill.
Du kan se alla inskickade klagomål.
Du kan skicka in egna klagomål och kunna bifoga en bild-fil.
Du kan redigera och radera dina egna klagomål på profil-sidan.

Jag har använt mig av MockAPI: https://mockapi.io/clone/6a035fe72afe8349b4b5252b.

Sätt upp det:
1 Ha Node.js installerat
2 Klona repot
3 Installera beroenden: npm install

Appen kräver två terminaler som körs samtidigt:

Multerserver:
node server.js

React-Appen:
npm run dev

Öppna sedan [http://localhost:5173](http://localhost:5173) i webbläsaren.
